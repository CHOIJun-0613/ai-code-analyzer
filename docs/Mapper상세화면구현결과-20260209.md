## 과제1: MyBatisMapper 노드에 source 속성 추가

### 1-1. Pydantic 모델에 source 필드 추가
- **파일**: `server/csa/models/entities/mybatis.py`
- `MyBatisMapper` 클래스에 `source: str = ""` 필드 추가
- Mapper 파일 원본 소스 코드를 저장하기 위한 속성

### 1-2. XML 파서에서 source 저장
- **파일**: `server/csa/services/java_analysis/mybatis.py`
- `parse_mybatis_xml_file()` 함수에서 이미 읽고 있던 `xml_content` 변수를 MyBatisMapper 생성 시 `source=xml_content`로 전달
- XML Mapper 파일의 원본 내용이 그대로 저장됨

### 1-3. Java Interface 파서에서 source 저장
- **파일**: `server/csa/services/java_analysis/mybatis.py`
- `extract_mybatis_mappers_from_classes()` 함수에서 Java Class 객체의 source를 `source=cls.source or ""`로 전달
- @Mapper 어노테이션이 붙은 Java Interface의 소스도 저장됨

### 1-4. Neo4j 저장 쿼리에 source 추가
- **파일**: `server/csa/services/graph_db/persistence_nodes.py`
- `_create_mybatis_mapper_node_tx()` 함수의 MERGE 쿼리 SET절에 `m.source = $source` 추가
- tx.run 파라미터에 `source=mapper.source or ""` 추가

## 과제2: SQL Mapper 상세 화면 구성

### 2-1. 백엔드 API - Mapper 상세 엔드포인트 추가
- **파일**: `server/app/api/v1/endpoints/mappers.py`
- **엔드포인트**: `GET /api/v1/mappers/projects/{project_name}/mappers/{mapper_name}`
- **쿼리 파라미터**: `package_name` (선택사항, 동명 Mapper 구분용)
- **접근 제어**: `deps.verify_project_access` 적용
- **반환 데이터**:
  - MyBatisMapper 노드 전체 속성 (name, logical_name, type, file_extension, namespace, file_path, package_name, source, ai_description, updated_at, project_name)
  - sql_statements: JSON 문자열을 파싱하여 리스트로 반환
  - methods: JSON 문자열을 파싱하여 리스트로 반환
  - sql_count: 연결된 SqlStatement 노드 개수

### 2-2. 프론트엔드 - MapperDetails 페이지 생성
- **파일**: `client/src/pages/MapperDetails.tsx` (신규 생성)
- SqlDetails.tsx 패턴을 참조하여 구현

#### Header 구성:
- FileCode 아이콘 (indigo 배지)
- package_name 표시 (font-mono)
- `name.file_extension` 형식으로 Mapper 이름 표시
- type 배지 (xml: emerald, interface: violet)
- logical_name 표시
- updated_at 표시

#### 탭 구성 (3개):

| 탭 | 내용 |
|----|------|
| **개요** | 파일 경로(file_path) 표시, ai_description을 Markdown으로 렌더링 (react-markdown + remarkGfm) |
| **등록 SQL** | sql_statements의 id, logical_name, sql_type으로 테이블 구성. id 클릭 시 SqlDetails 화면으로 이동 (`/projects/{projectName}/sqls/{sqlId}?mapper={mapperName}`) |
| **Mapper 소스** | SourceCodeViewer 컴포넌트 사용 (SqlDetails의 SQL Source 탭과 동일). XML은 language="xml", Java는 language="java" |

#### SQL Type 배지 색상:
- SELECT: 파란색 (blue)
- INSERT: 녹색 (green)
- UPDATE: 주황색 (amber)
- DELETE: 빨간색 (red)

### 2-3. 라우팅 등록
- **파일**: `client/src/App.tsx`
- lazy import 추가: `const MapperDetails = lazy(() => import('./pages/MapperDetails'))`
- 라우트 등록: `projects/:projectName/mappers/:mapperName`

### 2-4. MapperList에서 상세 화면 이동 추가

## 검증 방법

1. **백엔드 검증**: 서버 실행 후 `GET /api/v1/mappers/projects/{project}/mappers/{mapper}` API 호출하여 source 포함 여부 확인
2. **프론트엔드 검증**: MapperList에서 Mapper 행 클릭 → MapperDetails 페이지 이동 → 3개 탭 전환 확인
3. **다크모드 검증**: 설정에서 테마 전환 후 MapperDetails 화면 정상 표시 확인
4. **i18n 검증**: 언어 전환(한국어/English)하여 번역 정상 표시 확인
5. **SQL 이동 검증**: 등록 SQL 탭에서 SQL id 클릭 시 SqlDetails로 정상 이동 확인
6. **source 저장 검증**: 코드 정적 분석 재실행 후 Neo4j에서 MyBatisMapper 노드의 source 속성에 XML 원본이 저장되었는지 확인

# 개선 작업 계획: Toast 알림 도입 (react-hot-toast)

**작성일**: 2026-01-02
**작성자**: Antigravity

## 1. 개요
기존의 `alert()` 및 `confirm()` 기반의 사용자 알림을 모던한 UI의 Toast 알림(`react-hot-toast`)으로 대체하여 사용자 경험(UX)을 개선합니다.

## 2. 변경 대상
- **라이브러리 추가**: `react-hot-toast`
- **전역 설정**: `Layout.tsx`에 `<Toaster />` 추가
- **페이지별 적용**:
  - `Login.tsx`: 로그인 실패/성공 알림
  - `Analysis.tsx`: 분석 시작, 완료, 에러 알림
  - `CodeAiAnalysis.tsx`: AI 분석 관련 알림
  - `ProjectDetails.tsx`: 리포트 생성, 저장 관련 알림
  - `Admin/*.tsx`: 사용자/그룹 관리 관련 알림

## 3. 상세 계획

### 3.1 패키지 설치
```bash
npm install react-hot-toast
```

### 3.2 전역 Toaster 설정
`client/src/components/Layout.tsx`에 `Toaster` 컴포넌트를 배치하여 앱 전역에서 알림이 표시되도록 설정합니다.

### 3.3 Alert 대체 작업
각 컴포넌트에서 `alert('message')`를 `toast.success('message')` 또는 `toast.error('message')`로 변경합니다.

## 4. 검증 계획
- 로그인 실패 시 붉은색 에러 토스트 확인
- 분석 시작 시 녹색 성공 토스트 확인
- 각 기능별 정상 동작 및 알림 표시 확인

## 5. 작업 결과
- `react-hot-toast` 설치 및 `Layout.tsx`에 `Toaster` 설정 완료.
- `Analysis.tsx`, `CodeAiAnalysis.tsx`, `Login.tsx`, `ProjectDetails.tsx`, `Admin/UserManagement.tsx`, `Admin/GroupManagement.tsx`의 `alert()` 호출을 `toast`로 대체 완료.
- **추가 작업**: `Analysis.tsx`와 `CodeAiAnalysis.tsx`에서 분석 시작/중지/완료/실패 등 모든 상태 변화에 대해 Toast 알림이 누락되지 않도록 보완 적용 완료.
- **UI 개선**: `AnalysisHistoryList.tsx`, `Admin/UserManagement.tsx`, `Admin/GroupManagement.tsx`의 기본 `confirm()` 대화상자를 `ConfirmModal` 컴포넌트로 교체하여 일관된 UI(로켓/경고 아이콘 스타일) 적용 완료.
- `Admin/UserManagement.tsx`의 엑셀 업로드 로직 구문 오류 수정 완료.
- 빌드 및 설치 완료 (사용자 확인됨).

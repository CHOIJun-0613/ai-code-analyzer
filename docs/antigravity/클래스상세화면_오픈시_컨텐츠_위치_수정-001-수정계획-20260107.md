# 클래스상세화면 오픈시 컨텐츠 위치 수정

## 1. 목표 (Goal)
- 프로젝트 상세화면에서 클래스 상세화면으로 진입 시, 화면 스크롤이 항상 최상단(클래스 명)에 위치하도록 수정한다.
- 현재 '개요' 탭의 Description 영역 등으로 스크롤이 내려가 있는 현상을 해결한다.

## 2. 분석 (Analysis)
- **원인 파악**:
  - `client/src/components/Layout.tsx`에서 라우트 변경(`location.pathname`) 시 스크롤을 최상단으로 초기화하는 로직이 존재함.
  - 그러나 `mainContentRef`가 `overflow-hidden` 속성을 가진 래퍼 `div`에 연결되어 있어, 실제 스크롤이 발생하는 내부 `div`(`overflow-auto`)의 스크롤 위치를 제어하지 못하고 있음.
  - 이로 인해 화면 전환 시 이전 스크롤 위치가 유지되거나, 브라우저의 기본 동작으로 인해 원치 않는 위치로 스크롤되는 현상이 발생함.

## 3. 변경 범위 (Scope)
- **대상 파일**: `client/src/components/Layout.tsx`
- **변경 내용**:
  - `mainContentRef`를 실제 스크롤이 발생하는 `div` 요소로 이동시킨다.

## 4. 단계별 계획 (Steps)

### Step 1: Layout 컴포넌트 수정
- `client/src/components/Layout.tsx` 파일 수정
- `mainContentRef`를 `div.flex-1.flex.flex-col.overflow-hidden.relative`에서 그 하위의 `div.flex-1.overflow-auto`로 이동.

### Step 2: 검증 (Verification)
- 코드 리뷰를 통해 `ref`가 올바른 요소에 부착되었는지 확인.
- `useEffect` 내의 `scrollTop = 0` 로직이 실제 스크롤 컨테이너에 적용되는지 확인.

## 5. 검증 계획 (Verification Plan)
### Automated Tests
- 현재 UI 스크롤 동작을 검증하는 자동화 테스트는 없으므로, 코드 구조 확인으로 대체한다.

### Manual Verification
- (사용자 측) 프로젝트 상세화면 -> 클래스 상세화면 진입 시 스크롤이 최상단에 위치하는지 확인.

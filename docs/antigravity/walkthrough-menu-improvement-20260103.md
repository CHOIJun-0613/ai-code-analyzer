# Walkthrough - Menu and Icon Improvement (2026-01-03)

사이드바 메뉴 명칭, 아이콘 및 관리 페이지의 타이틀을 사용자 요청에 맞춰 개선했습니다.

## 주요 변경 사항

### 1. 메뉴 명칭 수정 (i18n)

- **관리 -> 시스템 관리**:
  - 사이드바의 관리 메뉴 그룹 및 관리 대시보드 페이지의 타이틀을 "시스템 관리"로 변경했습니다. (`ko/translation.json`, `en/translation.json` 업데이트)
- **설정 -> 화면 설정**:
  - 사이드바 하단의 설정 버튼 명칭을 "화면 설정"으로 변경하여 기능(테마, 언어 등)을 더 명확하게 표현했습니다.

### 2. 아이콘 개선

- **시스템 관리 아이콘 변경**:
  - 기존의 `Users` 아이콘 대신 시스템 관리 및 보안의 의미를 더 잘 전달하는 `ShieldCheck` 아이콘으로 교체했습니다.

## 수정된 파일

- `client/src/locales/ko/translation.json`: 한국어 메뉴 명칭 수정
- `client/src/locales/en/translation.json`: 영어 메뉴 명칭 수정 (Screen Settings)
- `client/src/components/Layout.tsx`: 사이드바 아이콘 교체 및 미사용 임포트 제거

## 테스트 방법

1. 사이드바의 "시스템 관리" 메뉴 명칭과 방패 모양의 아이콘을 확인합니다.
2. 사이드바 하단의 "화면 설정" 버튼 명칭을 확인합니다.
3. "시스템 관리" 메뉴를 클릭하여 관리 대시보드 페이지로 이동한 후, 페이지 타이틀이 "시스템 관리"로 표시되는지 확인합니다.
4. 언어 설정을 변경하여 영어 환경에서도 명칭이 올바르게 반영되었는지 확인합니다 (Screen Settings).

# 프로젝트 상세화면 검색컴포넌트 개선

## 1. 목표 (Goal)
- 프로젝트 상세화면의 패키지 및 클래스 목록 검색 컴포넌트에 검색어 초기화('X') 버튼을 추가한다.
- 검색 컴포넌트의 안내 텍스트(Placeholder)에 다국어(한국어)를 적용한다.
- 검색 컴포넌트가 Dark/Light 모드에서 일관된 스타일을 유지하도록 개선한다.

## 2. 분석 (Analysis)
- **대상 파일**:
  - `client/src/pages/ProjectDetails.tsx`: 패키지 및 클래스 검색 입력 필드가 위치함.
  - `client/src/locales/ko/translation.json`: 한국어 번역 리소스.
- **현황**:
  - 현재 검색 입력 필드에는 검색 아이콘만 있고, 입력된 텍스트를 한 번에 지우는 기능이 없음.
  - 한국어 모드에서도 검색 Placeholder가 영어로 표시됨.
  - 기존 Input 스타일은 이미 Dark 모드를 지원하고 있으나, 새로 추가될 버튼의 스타일링이 필요함.

## 3. 변경 범위 (Scope)
- **파일**:
  - `client/src/pages/ProjectDetails.tsx`
  - `client/src/locales/ko/translation.json`

## 4. 단계별 계획 (Steps)

### Step 1: 한국어 리소스 파일 수정 (`ko/translation.json`)
- `projectDetails` 섹션의 다음 키 값을 한국어로 번역:
  - `searchPackages`: "Search packages..." -> "패키지 검색..."
  - `searchClasses`: "Search classes (physical or logical name)..." -> "클래스 검색 (물리명 또는 논리명)..."

### Step 2: 프로젝트 상세화면 수정 (`ProjectDetails.tsx`)
- **패키지 검색 컴포넌트 개선**:
  - Input 우측에 'X' 아이콘 버튼 추가.
  - `packageSearchQuery` 값이 있을 때만 버튼 표시.
  - 버튼 클릭 시 `setPackageSearchQuery('')` 호출하여 검색어 초기화.
  - Dark/Light 모드에 맞는 스타일 적용 (hover 효과 등).
- **클래스 검색 컴포넌트 개선**:
  - Input 우측에 'X' 아이콘 버튼 추가.
  - `searchQuery` 값이 있을 때만 버튼 표시.
  - 버튼 클릭 시 `setSearchQuery('')` 호출하여 검색어 초기화.
  - Dark/Light 모드에 맞는 스타일 적용.

## 5. 검증 계획 (Verification Plan)
### Manual Verification
- **검색어 초기화 기능**:
  - 패키지 및 클래스 검색창에 텍스트 입력 후 'X' 버튼이 나타나는지 확인.
  - 'X' 버튼 클릭 시 텍스트가 지워지고 목록이 전체 조회 상태로 돌아가는지 확인.
- **다국어 적용**:
  - 언어 설정이 한국어일 때 Placeholder가 한국어로 표시되는지 확인.
- **스타일 확인**:
  - Light 모드와 Dark 모드에서 검색 컴포넌트 및 'X' 버튼이 적절하게 보이는지 확인.

## Verification Plan

### Automated Tests

- `npm run dev`를 통해 로컬 서버 실행 후 브라우저 확인.

### Manual Verification

1. **메뉴 확인**:
   - 사이드바에서 '대시보드' 클릭 시 `/`로 이동하는지 확인.
   - '대시보드' 하위 메뉴가 사라졌는지 확인.
   - 'Project List' 메뉴명이 언어 설정에 따라 바뀌는지 확인.
2. **프로젝트 목록 화면 확인**:
   - 제목, 설명, 테이블 헤더 등이 한글/영문으로 잘 나오는지 확인.
   - 검색창에 텍스트 입력 시 'x' 버튼이 나타나는지 확인.
   - 'x' 버튼 클릭 시 검색어가 초기화되는지 확인.

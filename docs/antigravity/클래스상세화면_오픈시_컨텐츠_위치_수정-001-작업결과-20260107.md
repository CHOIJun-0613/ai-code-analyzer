# 클래스상세화면 오픈시 컨텐츠 위치 수정

## 1. 작업 요약 (Summary)
- **목표**: 프로젝트 상세화면에서 클래스 상세화면으로 진입 시, 스크롤이 항상 최상단에 위치하도록 수정.
- **결과**: `Layout.tsx` 컴포넌트의 스크롤 제어 로직을 수정하여, 페이지 전환 시 스크롤이 정상적으로 초기화되도록 조치함.

## 2. 주요 변경 사항 (Changes)
- **파일**: `client/src/components/Layout.tsx`
- **내용**:
  - `mainContentRef`가 기존에는 스크롤이 발생하지 않는 상위 `div`(`overflow-hidden`)에 연결되어 있었음.
  - 이를 실제 스크롤이 발생하는 하위 `div`(`overflow-auto`)로 이동시켜, `useEffect`를 통한 스크롤 초기화(`scrollTop = 0`)가 정상 동작하도록 수정함.

```tsx
// Before
<div ref={mainContentRef} className="flex-1 flex flex-col overflow-hidden relative">
    {/* ... */}
    <div className="flex-1 overflow-auto">
        {/* ... */}
    </div>
</div>

// After
<div className="flex-1 flex flex-col overflow-hidden relative">
    {/* ... */}
    <div ref={mainContentRef} className="flex-1 overflow-auto">
        {/* ... */}
    </div>
</div>
```

## 3. 테스트 결과 (Verification)
- **검증 방법**:
  - 코드 리뷰를 통해 `ref`가 올바른 DOM 요소(스크롤 컨테이너)에 부착되었는지 확인.
  - 라우트 변경 시 동작하는 `useEffect` 로직이 해당 `ref`를 참조하고 있음을 확인.

## 4. Git Commit Message
```
fix: 클래스 상세화면 진입 시 스크롤 위치 초기화 문제 수정

- 실제 스크롤이 발생하는 내부 div로 ref 이동
```

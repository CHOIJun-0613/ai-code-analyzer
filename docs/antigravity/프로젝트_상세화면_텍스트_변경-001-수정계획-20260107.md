# 프로젝트 상세화면 텍스트 변경 및 다국어 지원 개선

## 1. 목표 (Goal)
- 프로젝트 상세화면의 'Project Information' 및 'Code Statistics' 카드의 텍스트를 사용자 요구사항에 맞춰 변경한다.
- 다국어(영어/한국어) 지원을 개선하여 명확한 의미를 전달한다.

## 2. 분석 (Analysis)
- **대상 파일**:
  - `client/src/locales/en/translation.json`
  - `client/src/locales/ko/translation.json`
  - `client/src/pages/ProjectDetails.tsx` (키 확인 완료, 코드 수정 불필요)
- **변경 내용**:
  - `translation.json` 파일 내의 `projectDetails` 섹션의 값을 수정한다.
  - 사용자 요청에 포함된 오타(주석/공백 라인수에 LLOC 표기)는 문맥에 맞게 수정하여 적용한다.
    - Comment Lines: '전체 주석 라인수 (LLOC)' -> '전체 주석 라인수 (CLOC)'
    - Blank Lines: '전체 공백 라인수 (LLOC)' -> '전체 공백 라인수'

## 3. 변경 범위 (Scope)
- **파일**:
  - `client/src/locales/en/translation.json`
  - `client/src/locales/ko/translation.json`

## 4. 단계별 계획 (Steps)

### Step 1: 영어 리소스 파일 수정 (`en/translation.json`)
- `projectDetails` 섹션의 다음 키 값을 수정:
  - `repository`: "Repository" -> "Repository URL"
  - `codeLines`: "Code Lines (LLOC)" -> "Logic Lines (LLOC)"
  - `validJavaFiles`: "Valid Java Files" -> "Valid Code Files"

### Step 2: 한국어 리소스 파일 수정 (`ko/translation.json`)
- `projectDetails` 섹션의 다음 키 값을 수정:
  - `projectInformation`: "Project Information" -> "프로젝트 정보"
  - `edit`: "Edit" -> "편집"
  - `applicationName`: "Application Name" -> "어플리케이션명"
  - `framework`: "Framework" -> "프레임워크"
  - `repository`: "Repository" -> "소스 리파지토리 URL"
  - `path`: "Path" -> "분석대상 소스 루트경로"
  - `codeStatistics`: "Code Statistics" -> "코드 통계 정보"
  - `lineStatistics`: "Line Statistics" -> "코드 라인 통계"
  - `totalLines`: "Total Lines (PLOC)" -> "전체 코드 라인수 (PLOC)"
  - `codeLines`: "Code Lines (LLOC)" -> "전체 로직 라인수 (LLOC)"
  - `commentLines`: "Comment Lines (CLOC)" -> "전체 주석 라인수 (CLOC)"
  - `blankLines`: "Blank Lines" -> "전체 공백 라인수"
  - `fileStatistics`: "File Statistics" -> "소스 파일 통계"
  - `totalFiles`: "Total Files" -> "전체 파일 수"
  - `validJavaFiles`: "Valid Java Files" -> "유효 소스 파일 수"
  - `xmlFiles`: "XML Files" -> "XML 파일 수"
  - `configFiles`: "Config Files" -> "설정 파일 수"
  - `ignored`: "Ignored" -> "분석 비대상 파일 수"
  - `lastUpdated`: "최근 업데이트" -> "최종 변경 일시"

## 5. 검증 계획 (Verification Plan)
### Manual Verification
- 프로젝트 상세화면에 접속하여 변경된 텍스트가 영어/한국어 모드에서 올바르게 표시되는지 확인한다.

# AI 분석 상태 유지 기능 검증 가이드

## 변경 사항 요약

### 백엔드 (`server`)
- **API 수정**: `/ai/active` 및 `/ai/{job_id}` 엔드포인트가 작업의 파라미터(`params`)를 함께 반환하도록 수정되었습니다. 이를 통해 프론트엔드가 작업의 설정(프로젝트 명, 노드 타입 등)을 알 수 있습니다.

### 프론트엔드 (`client`)
- **상태 복원 로직 추가**: `CodeAiAnalysis` 페이지 진입 시 활성 작업이 있다면, 백엔드로부터 받은 파라미터로 화면 설정을 복원하고, 기존 로그를 가져와서 표시하도록 수정되었습니다.

## 검증 절차

### 1. AI 분석 시작
1.  **AI 분석** 메뉴로 이동합니다.
2.  **Target Project**를 선택하고 분석 설정을 구성합니다.
3.  **Start Analysis** 버튼을 클릭하여 분석을 시작합니다.
4.  분석이 시작되고 로그가 올라오는 것을 확인합니다.

### 2. 화면 이동 (상태 유지 테스트)
1.  분석이 실행 중인 상태에서 **Dashboard**나 **Static Analysis** 등 다른 메뉴를 클릭하여 화면을 이동합니다.
2.  잠시(약 5~10초) 기다립니다.

### 3. 화면 복귀 및 확인
1.  다시 **AI 분석** 메뉴로 돌아옵니다.
2.  다음 사항들이 올바르게 복원되었는지 확인합니다:
    - **상태**: `Running` (또는 그 사이 완료되었다면 `Completed`) 상태여야 합니다.
    - **설정**: 이전에 선택했던 프로젝트와 설정값들이 그대로 표시되어야 합니다.
    - **로그**: "View Logs"를 클릭했을 때, 화면을 이동하기 전의 로그부터 현재까지의 모든 로그가 보여야 합니다.
    - **진행률**: 진행률 바가 현재 진행 상황을 올바르게 표시해야 합니다.

## 예상 결과
- 화면을 이동했다가 돌아와도 분석 작업이 중단되지 않고, 사용자가 보고 있던 화면 상태(설정, 로그 등)가 그대로 유지되어야 합니다.

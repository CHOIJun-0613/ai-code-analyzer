# 메서드 상세화면 구현 계획 및 결과

## 개요

사용자가 클래스 상세 화면의 메서드 목록에서 특정 메서드를 클릭했을 때, 해당 메서드의 상세 정보를 보여주는 화면을 구현합니다. 이 화면은 클래스 상세 화면과 유사한 디자인을 유지하며, 메서드의 기본 정보, 메트릭, 소스 코드 및 호출 관계를 포함합니다.

## 구현 계획

### 1. 백엔드 API 구현

- `server/app/api/v1/endpoints/projects.py` 파일에 특정 메서드의 상세 정보를 조회하는 API 엔드포인트 추가
  - 경로: `GET /projects/{project_name}/classes/{class_name}/methods/{method_name}`
  - 기능: 메서드의 기본 속성(이름, 리턴 타입, 가시성, LOC, 복잡도 등), 어노테이션, 소스 코드, 호출 정보 조회

### 2. 프론트엔드 i18n 번역 추가

- `client/src/locales/ko/translation.json` 및 `client/src/locales/en/translation.json`에 `methodDetails` 섹션 추가
  - 필요한 문구: 메서드 상세, 기본 정보, 소스 코드, 호출 정보 등

### 3. 프론트엔드 라우팅 설정

- `client/src/App.tsx`에 메서드 상세 페이지를 위한 라우트 추가
  - 경로: `/projects/:projectName/classes/:className/methods/:methodName`

### 4. 메서드 상세 페이지 컴포넌트 구현

- `client/src/pages/MethodDetails.tsx` 생성
  - 클래스 상세 정보와 유사한 레이아웃 구성
  - 상단: 패키지/클래스/메서드 정보 및 주요 메트릭 카드
  - 탭 영역:
    - **Info**: 설명(AI 분석 포함), 어노테이션, 파라미터 정보
    - **Source**: 메서드 소스 코드 뷰어
    - **Calls**: 해당 메서드가 호출하는 다른 메서드 목록

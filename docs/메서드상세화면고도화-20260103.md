# 메서드 상세 화면 고도화 - 20260103

## 작업 개요

메서드 상세 화면에 호출 정보의 상세 컬럼(논리명, 리턴 타입)을 추가하고, 해당 메서드의 실행 흐름을 시각화하기 위한 시퀀스 다이어그램 탭을 구현하였습니다.

## 주요 변경 사항

### 1. 백엔드 (API 및 서비스)

- **`projects.py` (API)**: `get_method_details` 호출 시 반환되는 `calls` 리스트에 대상 메서드의 `logical_name`과 `return_type`을 포함하도록 Cypher 쿼리를 수정하였습니다.
- **`class_reports.py` (API)**: 특정 메서드의 시퀀스 다이어그램을 생성하는 엔드포인트를 추가하였습니다.
  - `GET /projects/{project_name}/classes/{class_name}/methods/{method_name}/reports/sequence`
- **`class_report_service.py` (Service)**: 클래스 레벨의 시퀀스 다이어그램 생성 로직을 재사용하여 메서드 레벨의 다이어그램을 생성하는 `generate_method_sequence_diagram_md` 함수를 구현하였습니다.

### 2. 프론트엔드 (UI)

- **`MethodDetails.tsx`**:
  - **호출 정보 테이블**: '대상 논리명'과 '리턴' 컬럼의 너비를 조정하고 `truncate` 속성을 추가하여 데이터 중첩 현상을 해결하였습니다. 마우스 오버 시 전체 내용을 확인할 수 있도록 `title` 속성을 적용했습니다.
  - **Complexity 도움말**: 'Complexity' 카드에 도움말(`?`) 아이콘을 추가하고, 클릭 시 인지복잡도(Cognitive Complexity)의 계산 방식과 SonarSource 권장 기준을 보여주는 팝업(모달)을 구현하였습니다.
  - **복잡도 기준 업데이트**: 인지복잡도 점수에 따른 상태 라벨(양호, 관리 필요, 리팩토링 필요)과 색상을 최신 가이드라인에 맞춰 업데이트했습니다.
  - **시퀀스 다이어그램 탭**: 새로운 탭을 추가하고, `MermaidDiagram` 컴포넌트를 사용하여 메서드의 호출 흐름을 가시화하였습니다.
  - **다국어 지원**: 시퀀스 다이어그램, 테이블 컬럼 및 복잡도 도움말에 대한 다국어 키를 추가하였습니다.
- **`translation.json`**: `methodDetails` 하위에 `targetLogicalName`, `targetReturnType`, `sequenceDiagram` 키를 추가하였습니다 (KO/EN).

### 3. 컴포넌트

- **`MermaidDiagram.tsx`**: 시퀀스 다이어그램 렌더링을 담당하며, 다크/라이트 모드 테마 대응이 되어 있습니다.

## 테스트 결과

- 메서드 상세 화면에서 '호출 정보' 탭 클릭 시 대상 메서드의 논리명과 리턴 타입이 정상적으로 표시됨.
- '시퀀스 다이어그램' 탭 클릭 시 해당 메서드를 기점으로 하는 Mermaid 시퀀스 다이어그램이 정상적으로 렌더링됨.
- 다크 모드 전환 시 시퀀스 다이어그램의 테마가 적절히 변경됨을 확인.

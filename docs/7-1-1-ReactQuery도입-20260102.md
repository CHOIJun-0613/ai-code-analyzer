## 1. 작업 개요

### 1.1 배경

현재 AI Code Analyzer의 클라이언트는 서버 상태 관리를 `useEffect` + `axios`로 처리하고 있으며, 다음과 같은 문제점이 있습니다:

- **캐싱 부재**: 매번 API 요청으로 불필요한 네트워크 트래픽 발생
- **수동 상태 관리**: 로딩/에러 상태를 컴포넌트마다 반복적으로 관리
- **재시도 미지원**: API 요청 실패 시 자동 재시도 없음
- **코드 중복**: 동일한 패턴의 데이터 fetching 로직이 여러 컴포넌트에 분산

### 1.2 목표

**React Query (TanStack Query)**를 도입하여:

1. ✅ 서버 상태 관리 표준화
2. ✅ 자동 캐싱으로 성능 향상 (API 요청 80% 감소)
3. ✅ 로딩/에러 상태 자동 관리로 코드 간소화
4. ✅ 자동 재시도 및 무효화(Invalidation)로 안정성 향상
5. ✅ 개발자 경험(DX) 개선 (DevTools 활용)

### 1.3 기대 효과

| 항목 | 개선 전 | 개선 후 | 개선율 |
|------|---------|---------|--------|
| **API 요청 수** | 매번 요청 | 5분 캐싱 | **80% 감소** |
| **로딩 상태 관리** | 수동 (useState) | 자동 (isLoading) | **코드 30% 감소** |
| **에러 처리** | 수동 (try-catch) | 자동 (isError, retry) | **안정성 향상** |
| **코드 중복** | 높음 | 낮음 | **유지보수성 향상** |

## 2. 현황 분석

### 2.1 현재 데이터 fetching 패턴

#### 전형적인 패턴 (useEffect + axios)

```typescript
// 현재 패턴 (예: Dashboard.tsx)
const [projects, setProjects] = useState([]);
const [loading, setLoading] = useState(false);
const [error, setError] = useState(null);

useEffect(() => {
  const fetchProjects = async () => {
    setLoading(true);
    try {
      const response = await client.get('/projects/');
      setProjects(response.data);
    } catch (err) {
      setError(err);
    } finally {
      setLoading(false);
    }
  };
  fetchProjects();
}, []);

// JSX에서 수동 로딩/에러 처리
{loading && <div>Loading...</div>}
{error && <div>Error: {error.message}</div>}
{projects.map(...)}
```

**문제점**:
- 매번 컴포넌트 마운트 시 API 요청
- 로딩/에러 상태를 수동으로 관리
- 재시도 로직 없음
- 캐싱 없음

### 4.2 QueryClient 설정

#### `client/src/main.tsx`

```typescript
import { StrictMode } from 'react';
import { createRoot } from 'react-dom/client';
import { QueryClient, QueryClientProvider } from '@tanstack/react-query';
import { ReactQueryDevtools } from '@tanstack/react-query-devtools';
import App from './App.tsx';
import './index.css';
import './i18n';

// QueryClient 생성 (전역 설정)
const queryClient = new QueryClient({
  defaultOptions: {
    queries: {
      // 전역 기본값
      staleTime: 5 * 60 * 1000, // 5분 캐싱
      gcTime: 10 * 60 * 1000,   // 10분 후 가비지 컬렉션
      retry: 3,                  // 실패 시 3번 재시도
      refetchOnWindowFocus: false, // 윈도우 포커스 시 재요청 비활성화
    },
    mutations: {
      retry: 1, // 뮤테이션은 1번만 재시도
    },
  },
});

createRoot(document.getElementById('root')!).render(
  <StrictMode>
    <QueryClientProvider client={queryClient}>
      <App />
      <ReactQueryDevtools initialIsOpen={false} />
    </QueryClientProvider>
  </StrictMode>,
);
```

**설정 설명**:
- **staleTime**: 데이터가 "신선"하다고 간주되는 시간 (5분 동안 재요청 없음)
- **gcTime** (cacheTime 대체): 메모리에서 캐시를 유지하는 시간
- **retry**: API 요청 실패 시 재시도 횟수
- **refetchOnWindowFocus**: 윈도우 포커스 시 자동 재요청 (프로덕션에서는 true 권장)

```typescript
import { useQuery } from '@tanstack/react-query';
```

```typescript
import { useQuery, useQueries } from '@tanstack/react-query';

// 통계 조회
const { data: stats, isLoading: isLoadingStats } = useQuery({
  queryKey: ['projects', projectName, 'stats'],
  queryFn: async () => {
    const response = await client.get(`/projects/${projectName}/stats`);
    return response.data;
  },
  enabled: !!projectName, // projectName이 있을 때만 요청

// 계층 구조 조회
const { data: hierarchy, isLoading: isLoadingHierarchy } = useQuery({

  queryFn: async () => {
    const response = await client.get(`/projects/${projectName}/hierarchy`);
    return response.data;
  },
  enabled: !!projectName,
});

// 또는 useQueries로 병렬 처리 (선택사항)
const results = useQueries({
  queries: [
    {
      queryKey: ['projects', projectName, 'stats'],
      queryFn: () => client.get(`/projects/${projectName}/stats`).then(res => res.data),
      enabled: !!projectName,
    },
    {
      queryKey: ['projects', projectName, 'hierarchy'],
      queryFn: () => client.get(`/projects/${projectName}/hierarchy`).then(res => res.data),
      enabled: !!projectName,

const [statsQuery, hierarchyQuery] = results;
```

- **병렬 요청 최적화**: useQueries로 여러 요청 동시 처리
- **조건부 요청**: enabled 옵션으로 불필요한 요청 방지
- **queryKey 계층화**: ['projects', name, 'stats'] 구조로 무효화 용이

#### Before (3초 간격 폴링)

```typescript
useEffect(() => {
```

#### After (React Query Polling)

```typescript
import { useQuery } from '@tanstack/react-query';

// 작업 상태 폴링
const { data: jobStatus } = useQuery({
  queryKey: ['analysis', 'job', activeJobId],
  queryFn: async () => {
    const response = await client.get(`/analysis/analyze/${activeJobId}`);
    return response.data;
  },
  enabled: !!activeJobId,
  refetchInterval: (query) => {
    const status = query.state.data?.status;
    // 완료/실패/취소 상태면 폴링 중지
    if (['completed', 'failed', 'cancelled'].includes(status)) {
      return false;
    }
    return 3000; // 3초 간격
  },
  staleTime: 0, // 폴링 데이터는 항상 최신으로
});

// 로그 폴링
const { data: logsData } = useQuery({
  queryKey: ['analysis', 'job', activeJobId, 'logs'],
  queryFn: async () => {
    const response = await client.get(`/analysis/analyze/${activeJobId}/logs`);
    return response.data;
  },
  enabled: !!activeJobId,
  refetchInterval: (query) => {
    const status = jobStatus?.status;
    if (['completed', 'failed', 'cancelled'].includes(status)) {
      return false;
    }
    return 3000;
  },
  staleTime: 0,
});
```

**개선 사항**:
- **자동 폴링**: refetchInterval로 간격 설정
- **조건부 중지**: 완료 시 자동으로 폴링 중지
- **메모리 관리**: 컴포넌트 언마운트 시 자동 정리

### 5.4 Mutation 활용 (CRUD 작업)

#### Before (사용자 생성)

```typescript
const handleCreateUser = async () => {
  setLoading(true);
  try {
    await client.post('/users/', newUser);
    // 수동으로 목록 재조회
    const response = await client.get('/users/');

  } catch (err) {
    setError(err);
  } finally {
    setLoading(false);
  }

```

#### After (Mutation + Invalidation)

```typescript
import { useMutation, useQueryClient } from '@tanstack/react-query';

const queryClient = useQueryClient();

const createUserMutation = useMutation({
  mutationFn: async (newUser) => {
    const response = await client.post('/users/', newUser);
    return response.data;
  },
  onSuccess: () => {
    // 사용자 목록 쿼리 무효화 (자동 재조회)
    queryClient.invalidateQueries({ queryKey: ['users'] });
  },
  onError: (error) => {
    console.error('사용자 생성 실패:', error);
  },
});

const handleCreateUser = () => {
  createUserMutation.mutate(newUser);
};

// JSX에서 로딩 상태 사용
{createUserMutation.isPending && <Spinner />}
{createUserMutation.isError && <ErrorMessage error={createUserMutation.error} />}
```

**개선 사항**:
- **자동 무효화**: onSuccess에서 자동으로 관련 쿼리 무효화
- **낙관적 업데이트 가능**: onMutate에서 즉시 UI 업데이트 (선택사항)
- **에러 처리 간소화**: isError, error 자동 제공

### 6.4 React Query v5 적용 사항

React Query v5에서는 다음과 같은 변경이 적용되었습니다:

1. **onSuccess 제거**: `useEffect`로 대체
   ```typescript
   // Before (v4)
   useQuery({
     queryKey: ['projects'],
     queryFn: fetchProjects,
     onSuccess: (data) => setSelectedProject(data[0])
   });

   // After (v5)
   const { data } = useQuery({ queryKey: ['projects'], queryFn: fetchProjects });
   useEffect(() => {
     if (data && data.length > 0) setSelectedProject(data[0]);
   }, [data]);
   ```

2. **cacheTime → gcTime**: 캐시 가비지 컬렉션 시간 명칭 변경

3. **제네릭 타입 명시**: TypeScript 안전성 향상
   ```typescript
   useQuery<ProjectStats>({ queryKey: ['stats'], queryFn: fetchStats });
   ```

## 8. 후속 작업

### 8.1 최적화 (선택사항)

1. **Optimistic Updates**: 낙관적 UI 업데이트로 즉각적인 피드백
   ```typescript
   const updateProjectMutation = useMutation({
     mutationFn: updateProject,
     onMutate: async (newData) => {
       // 쿼리 취소
       await queryClient.cancelQueries({ queryKey: ['projects', id] });

       // 이전 데이터 백업
       const previousData = queryClient.getQueryData(['projects', id]);

       // 낙관적 업데이트
       queryClient.setQueryData(['projects', id], newData);

       return { previousData };
     },
     onError: (err, newData, context) => {
       // 롤백
       queryClient.setQueryData(['projects', id], context.previousData);
     },
   });
   ```

2. **Prefetching**: 사용자 액션 예측하여 미리 데이터 로딩
   ```typescript
   const prefetchProject = (projectName: string) => {
     queryClient.prefetchQuery({
       queryKey: ['projects', projectName],
       queryFn: () => client.get(`/projects/${projectName}`).then(res => res.data),
     });
   };

   // 마우스 호버 시 프리페치
   <div onMouseEnter={() => prefetchProject(project.name)}>
     {project.name}
   </div>
   ```

3. **Infinite Queries**: 무한 스크롤 구현
   ```typescript
   const { data, fetchNextPage, hasNextPage } = useInfiniteQuery({
     queryKey: ['projects'],
     queryFn: ({ pageParam = 1 }) => fetchProjects(pageParam),
     getNextPageParam: (lastPage) => lastPage.nextPage,
   });
   ```

   - 동적 데이터 (분석 작업 상태): 0초
   - 사용자 설정: 1분

2. **queryKey 네이밍 컨벤션**: 일관성 유지

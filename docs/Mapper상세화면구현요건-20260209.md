## SQL Mapper 상세 화면 구현
- SQL Mapper 목록 테이블에서 Mapper를 클릭 하면 Mapper 상세화면 오픈
### 과제1) MyBatisMapper노드에 source 속성 추가 
- Neo4J DB의 MyBatisMapper노드에 source 속성 추가한다.
- 소스 코드 정적 분석할 때 Mapper file 내용을 그대로 MyBatisMapper.source에 저장한다.
### 과제2) SQL Mapper 상세 화면 구성 : 참조 클래스 상세 화면
1. header 부분 : Mapper아이콘 이미지, package_name,Mapper name + file_extension, type, logical_name, updated_at
2. 탭 구성 : '개요' , '등록 SQL' , 'Mapper 소스'  
- '개요' 탭 :
    - 파일 경로 :  MyBatisMapper.file_path 값 표기
    - Description - MyBatisMapper.ai_description값 표기
- '등록 SQL' 탭 : 
    - MyBatisMapper.sql_statements에서 'id'와 'logical_name', 'sql_type' 값으로 list table 구성
	- 'id'를 클릭하면 해당 SQL 상세화면으로 이동 
- 'Mapper 소스' 탭 :
    - MyBatisMapper.source 값을 표기한다.
	- 참조: SQL 상세화면의 "SQL Source" 탭의 editor와 동일한 컴포넌트 사용
3. 공통 기능:
- 화면 코드 추가 및 수정시에는 i18n 모드와 Dark/Light 모드를 반드시 적용한다.
- 구현계획이나 결과 작성은 한국어로 작성한다.
